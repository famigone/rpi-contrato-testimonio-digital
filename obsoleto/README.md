# Obsoleto — no se usa

Nada de esta carpeta es parte del contrato vigente: es el esquema **v1**
(namespace `/v1`) con sus comunes y su acto, y los ejemplos sin versión que
validaban contra él. Se conservan solo como registro histórico. El contrato
vigente es **v3**: validá contra [`xsd/v3/testimonio-digital.xsd`](../xsd/v3/testimonio-digital.xsd)
con los ejemplos de [`ejemplos/v3/`](../ejemplos/v3/).

`xmldsig-core-schema.xsd` es una copia, para que este bundle archivado siga
resolviendo sus imports por sí solo; el que usan v2 y v3 sigue en `xsd/`.
